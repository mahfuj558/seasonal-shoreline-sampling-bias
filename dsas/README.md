# DSAS v6.0 Outputs

This folder contains shoreline-change analysis outputs generated using the
Digital Shoreline Analysis System (DSAS) version 6.0.

## Study Area

Cox's Bazar–Teknaf coastal corridor, Bangladesh.

## Analysis Period

2021–2023 pilot study.

## DSAS Configuration

- DSAS version: 6.0.170
- Coordinate Reference System: EPSG:32646
- Baseline position: Offshore
- Transect spacing: 100 m
- Transect length/search distance: 10,000 m
- Smoothing distance: 300 m
- Confidence interval: 90%
- Default shoreline uncertainty: 10 m

## Main DSAS Outputs

The folder may include:

- Shoreline intersection tables
- DSAS rate tables
- Net Shoreline Movement (NSM)
- Shoreline Change Envelope (SCE)
- End Point Rate (EPR)
- Linear Regression Rate (LRR)
- Weighted Linear Regression (WLR)

## Important Note

All shoreline dates and shoreline attributes should be checked before the
final publication-quality analysis. The offshore baseline convention must be
maintained consistently when interpreting the sign of DSAS distance and
shoreline-change rates.
